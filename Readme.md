## 📌 Overview

PowerPilot AI is an intelligent **Building Energy Management System (BEMS)** that helps facility managers monitor energy consumption, predict peak demand, detect anomalies, and optimize electrical loads using AI.

This repository contains the **frontend dashboard**, designed as an enterprise-grade interface for interacting with the PowerPilot AI Agent powered by IBM technologies. The frontend includes a modern dashboard, real-time KPIs, interactive charts, AI chat integration, and monitoring panels. :contentReference[oaicite:0]{index=0}
